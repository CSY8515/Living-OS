# Living OS v2.099 - Dark Feature Background Matrix Hotfix

Living OS product version `v2.0.9.9` finalizes deterministic Dark Theme
feature-background resolution. The GitHub release tag is `v2.099`.

## Hotfix summary

- Finance resolves to its approved Dark feature background.
- Health resolves to its approved Dark feature background.
- Investment, Job, Vehicle, Housing, Food, Knowledge, Routine, and Growth
  resolve to their own exact Official feature backgrounds as a safe fallback.
- Missing dedicated Dark artwork remains explicitly `ASSET REQUIRED`; no Home,
  unrelated feature, generic image, or CSS filter is presented as completion.
- Complete matrix, A-to-B-to-A determinism, Official return, Dark re-entry, and
  exact context regression coverage is included.

## Compatibility and safety

- Living Home composition and navigation are unchanged.
- Feature routing, functional UI, domain logic, data, persistence, migration,
  and database contracts are unchanged.
- Existing Theme, Lock, Override, revision, and propagation architecture is
  unchanged.
- Existing assets are preserved; this release creates no substitute artwork.
