# Living OS Assets

This directory is reserved for version-controlled, non-user icons, templates, styles, and sanitized example material. Private runtime records and generated documents are prohibited.

living-os-final-answer.png preserves the original user-supplied Layout 1 crop for traceability.

living-os-layout1-style2.png is the production first-screen artwork: Layout 1 remains the immutable structure, while only the OS Ecosystem material, color, lighting, glass, depth, and premium rendering from Style 2 are transferred. Runtime code adds transparent navigation hotspots without redrawing or relocating the nine visible spaces.

## Subsystem World artwork

`subsystem-worlds/` contains ten 1672 × 941 production hero backgrounds for Finance, Investment, Job, Health, Vehicle, Housing, Food, Knowledge, Routine, and Personal Growth. They use the supplied OS Ecosystem screen only for the dark cosmic-organic illustration style, restrained olive-gold palette, cinematic lighting, glass, shadow, glow, material depth, and premium rendering. Its layout, tree, cards, labels, logos, and navigation are not copied.

Every background reserves the left side for accessible user information and places the world-defining object on the right. No text, controls, people, logos, or developer UI are baked into these assets.

`vehicle-world-portal.png` is the single approved Vehicle exception on the main Living OS World. It is a compact mobility sanctuary composited into the central lower gate; the nine blueprint object coordinates remain unchanged.

The assets were produced with the built-in ImageGen workflow and copied into the repository without removing their generated originals.
