# Official Concept Art Registry

This directory stores original Living OS Concept Art used as the visual source of
truth. v2.0.5 does not include a new official artwork asset.

## Preservation rules

- Never overwrite or edit an original file.
- Add a new versioned file for revisions.
- Do not recompress, crop, recolor, or remove metadata from the original.
- Derived implementation assets belong in a separate future asset directory.
- Record provenance and owner approval without embedding secrets or private
  personal data.

## File naming

```text
living-os_<surface>_concept_v<major>.<minor>_<YYYY-MM-DD>.<ext>
```

## Registry entry

For each original, add a row below.

| File | Version | Date | Surface | Approval | SHA-256 | Notes |
|---|---:|---|---|---|---|---|
| _No official source file registered in v2.0.5_ | — | — | — | Pending | — | Documentation foundation only |

Future implementation must link its design decision or visual test back to a
registered file and version.
